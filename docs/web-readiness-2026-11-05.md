# 분석 대기·출처 품질·모바일 점검 — 2026-11-05

## 적용 내용

- 분석 근거를 최대 6개 출처, 출처당 1,800자, 총 8,000자로 제한하고 동일 URL의 청크를 합친다. 모바일/일반 블로그 주소와 URL 인코딩만 다른 동일 게시물도 중복 근거로 세지 않는다. 저장 원문은 수정하지 않는다.
- LLM에는 자료 번호를 전달하고 본문 번호를 실제 출처 목록의 앵커로 연결한다. 존재하지 않는 번호는 링크 대신 확인 필요 문구를 표시한다. 인용 누락·범위 검사는 내용의 사실 여부 검증을 대신하지 않는다.
- ‘요이’ 검토에서 ‘요이 땅’ 설명이 현재 밈의 뜻으로 합쳐지는 오류를 확인해, 검토된 별개 표현을 설정에 명시하고 해당 제목의 자료를 제외했다. 모든 동음이의어를 자동으로 구분한다는 의미는 아니다.
- 모델이 블로그를 트렌드 점수의 출처로 인용한 사례가 있어, LLM은 네 항목만 작성하고 집계일·상태·점수는 실제 저장된 계산 결과로 별도 구성한다.
- 분석 중에도 근거 목록을 먼저 표시한다. 폴링을 1초 간격의 순차 요청으로 바꾸고, 이전 키워드의 느린 응답이 새 화면을 덮는 경합을 차단했다.
- 모바일에서 상단 검색창을 별도 줄로 배치하고 긴 출처·보관 키워드의 줄바꿈과 터치 영역을 조정했다. 초기 자동 초점으로 첫 화면이 아래로 이동하는 동작을 제거했다. 새벽 2시 전에는 전날 집계를 갱신 누락으로 안내하지 않는다.
- 빈 모델 답변은 완료로 저장하지 않는다. 네트워크 비활성 대기 제한을 기존 6,000초에서 120초로 조정했다. 이는 스트림 전체의 절대 실행 시간 제한은 아니다.

- Python 기본 테스트: 284개 통과, 로컬 대역 전용 테스트 4개는 기본 실행에서 건너뜀.

## 운영 반영

최종 설정의 실제 ‘요이’ 요청은 약 108초에 첫 본문, 약 122초에 완료됐다. ‘요이 땅’ 자료는 빠졌고 어원은 확인할 수 없다고 답했으며, 트렌드 값은 계산 결과와 일치했다. 다만 모델이 원문의 ‘영상을 봄’을 ‘영상을 올림’처럼 잘못 요약하거나 외국어 단어를 섞는 문제가 남았다. 번호 일치 검사만으로 이런 의미 오류를 판별하지 못하므로 사실 정확도가 완전히 해결됐다고 보고하지 않는다.
