- 응답 단계의 욕설 순화에 실제 노출된 가족·성별 비하 표현을 추가했다. 일반적인 연령·학년·지명 표현은 유지한다. 저장된 원문과 출처 URL은 변경하지 않는다. 이 필터는 알려진 표현의 문자열 처리이며 모든 비하 표현을 판별하지는 못한다.
- 인스타그램 계정 프로필과 검색 디렉터리는 검색 근거에서 제외한다. 개별 게시물 URL은 허용한다. 다른 동음이의어·관련성 오류를 모두 해결하는 필터는 아니다.
- 프롬프트에서 커뮤니티 글의 대표성을 가정하지 않고, 연령·성별 추정 및 점수만으로 확산 원인·유행 단계를 추론하지 않도록 지시한다. 외부 자료의 `<수집자료>` 포장과 지시 무시 원칙은 유지한다.
- 트렌드 프롬프트에 실제 집계일과 현재 상태를 보장하지 않는다는 문구를 전달한다.
